# Undo/Redo Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add one-step undo/redo for grade input mutations in the Deutsch Notenrechner single-page app.

**Architecture:** Two global snapshot variables (`undoSnapshot`, `redoSnapshot`) hold deep-clones of `data`. A new `saveDataWithUndo()` function replaces `saveData()` in grade-input functions only. Two navbar buttons call `undoData()` / `redoData()`.

**Tech Stack:** Vanilla JS, single file `index.html`, Flask backend irrelevant to this change.

### Task 1: Add global snapshot variables and core undo/redo functions

**Files:**
- Modify: `index.html` — JS state block around line 788, and the DATEN section around line 810

**Step 1: Add snapshot variables after existing state variables**

Find this block (around line 793):
```js
let pendingDelete = null;
```

Add directly after it:
```js
let undoSnapshot = null;
let redoSnapshot = null;
```

**Step 2: Add the four new functions after the existing `saveData()` function (around line 826)**

Insert after the closing `}` of `saveData()`:
```js
function saveDataWithUndo() {
    undoSnapshot = JSON.parse(JSON.stringify(data));
    redoSnapshot = null;
    saveData();
    updateUndoButtons();
}

function undoData() {
    if (!undoSnapshot) return;
    redoSnapshot = JSON.parse(JSON.stringify(data));
    data = undoSnapshot;
    undoSnapshot = null;
    saveData(); render(); updateUndoButtons();
}

function redoData() {
    if (!redoSnapshot) return;
    undoSnapshot = JSON.parse(JSON.stringify(data));
    data = redoSnapshot;
    redoSnapshot = null;
    saveData(); render(); updateUndoButtons();
}

function updateUndoButtons() {
    const u = document.getElementById('btn-undo');
    const r = document.getElementById('btn-redo');
    if (u) u.disabled = !undoSnapshot;
    if (r) r.disabled = !redoSnapshot;
}
```

**Step 3: Verify manually**

Open browser console and confirm `saveDataWithUndo`, `undoData`, `redoData`, `updateUndoButtons` are defined (no syntax errors).

**Step 4: Commit**
```bash

git commit -m "feat: add undo/redo snapshot functions"
```
